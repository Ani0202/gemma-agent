1. **Caps, context overflow, and patch recovery**

   Time/turn exceptions and ordinary agent exceptions—including a context-overflow exception—reach fallback collection. Tool/turn budget exits do too. Without a successful submission, the harness runs `git add -N .`, then `git diff --binary _swegemma_baseline`, falling back to `HEAD`, and strips protected files. Calling `submit_patch` is **not required**. See [agent_runner.py:932](/home/ubuntu/gemma-local/venv/lib/python3.13/site-packages/swegemma/harness/agent_runner.py:932), [exception handling:1026](/home/ubuntu/gemma-local/venv/lib/python3.13/site-packages/swegemma/harness/agent_runner.py:1026), and [fallback:1054](/home/ubuntu/gemma-local/venv/lib/python3.13/site-packages/swegemma/harness/agent_runner.py:1054).

   **It does not always collect the latest workspace.** Successful `submit_patch` stores a snapshot and sets `patch_submitted=True`; that disables fallback, even if the snapshot is empty or subsequent edits exist. See [execution.py:86](/home/ubuntu/gemma-local/venv/lib/python3.13/site-packages/swegemma/tools/execution.py:86) and [agent_runner.py:1048](/home/ubuntu/gemma-local/venv/lib/python3.13/site-packages/swegemma/harness/agent_runner.py:1048).

   Empty-patch paths despite edits include:
   - All changes are protected or ignored.
   - An empty submission snapshot disables later recovery.
   - Fallback fails; its diff exit code is unchecked and exceptions are merely logged.
   - An exception bypasses collection or escapes during cleanup; the outer worker records `agent_patch=''`.

   See [fallback failure handling:1063](/home/ubuntu/gemma-local/venv/lib/python3.13/site-packages/swegemma/harness/agent_runner.py:1063), [cleanup:1105](/home/ubuntu/gemma-local/venv/lib/python3.13/site-packages/swegemma/harness/agent_runner.py:1105), and [worker error result:495](/home/ubuntu/gemma-local/venv/lib/python3.13/site-packages/swegemma/evaluate.py:495).
